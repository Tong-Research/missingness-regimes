# A4 — residual mask — pre-registered 2026-08-27 10:35, BEFORE the run

## What is being tested

Paper 1 explains its negative result by saying the pattern's information "is already recoverable
from the observed values, so the pooled model loses nothing by ignoring the pattern". A4 takes
that literally: decompose the mask into the part the values predict and a residual, and give the
model only the residual.

Three arms, all fitted within the same `(seed, fold)` split so every comparison is paired:

| arm | design |
|---|---|
| `mean_impute` | mean-imputed values (frozen baseline) |
| `mean_indicator` | mean-imputed values + **raw** mask (frozen baseline) |
| `residual_indicator` | mean-imputed values + **residual** mask (A4) |

Residualisation is linear and leave-one-column-out. Linear because the outcome model is logistic
regression: the only part of the mask a linear model can use beyond the values *is* the linear
residual, so the residualiser is matched to the model class rather than merely cheap.
Leave-one-column-out because after mean imputation `x_ij` equals the column mean exactly when `j`
is missing, so including column `j` would let it nearly determine `m_ij` and collapse the residual
for a reason unrelated to the science.

## The relevant fact this is built on

On all three finished cohorts the raw mask indicator **hurts**: `mean_indicator` is below
`mean_impute` by $0.0036$ (colorectal), $0.0049$ (lung) and $0.0070$ (ovarian). Adding the mask to
a mean-imputed design costs more in degrees of freedom than it returns.

## Predictions

1. **`residual_indicator` beats `mean_indicator`.** Removing the part of the mask the values
   already carry should remove redundant columns and recover most of what the raw indicator loses.
   Expected direction positive; magnitude not predicted.
2. **`residual_indicator` does NOT beat `mean_impute` by the $0.002$ floor.** If Paper 1's
   explanation is right, what remains after residualising carries nothing.
3. **The permuted-mask null gains no less than the real mask.** As in the oracle ceiling, where
   the permuted null exceeded the real ceiling on 8 of 11 datasets.

## Withdrawal conditions

- **(a) If `residual_indicator` beats `mean_impute` by $\ge 0.002$ paired, on both dev cohorts,
  and by more than its own permuted null** — then the mask carries non-recoverable signal, Paper
  1's stated explanation is incomplete, and the discussion section that gives it must be rewritten
  before the paper is submitted.
- **(b) If prediction 1 fails** — residualising does not even recover what the raw indicator loses
  — then the redundancy account of why the indicator hurts is wrong, and the cause is something
  else (collinearity, scaling) that must be identified before A4 is reported either way.
- **(c) If the permuted null beats the real arm by $\ge 0.002$** — the design leaks. Stop and find
  it; do not report the real arm's number.

## Scope

Development cohorts **colorectal and lung** only. Ovarian and prostate are the holdout and the
runner refuses them without `--unblind`. 5 seeds x 5 folds, 40,000-record subsample, baseline
feature set. Frozen modules verified unchanged by `frozen_guard.py` before and after.
